# Supply Chain Analytics Internship

This repository contains my weekly task reports for a supply chain
analytics internship. All work uses publicly available data only.

## Week 1: Data Collection and Preliminary Analysis
Identified four public data sources and analysed logistics performance,
inventory management and transportation trends.

- **Sources:** World Bank LPI 2023 and LPI 2.0, US Census Bureau
  inventories-to-sales ratio (via FRED), UNCTAD Review of Maritime
  Transport 2025
- **Method:** manual collection from official publisher pages, quality
  checks, charts built with Python (matplotlib)
- **Key findings:** European economies lead the LPI; a country's overall
  score can hide weak individual measures such as port dwell time; the
  US inventory ratio spiked to a record 1.74 in April 2020; seaborne
  trade growth is slowing
- **Report:** [Week1_Data_Collection_Report.docx](Week1_Data_Collection/Week1_Data_Collection_Report.docx)
